# Archief

Bestaande/historische VVZ'49-flyers, bewaard als referentiemateriaal voor stijl en toon — geen
bron-bestanden (geen `.html`), puur ter inspiratie en als basis voor `docs/huisstijl-flyers.md`.

- `darttoernooi-lets-play-darts.jpg` — aankondiging van een darttoernooi (jeugd + senioren) in de
  kantine van VVZ'49. Basis voor de opbouw/stijlrichtlijnen in `docs/huisstijl-flyers.md`.

Heb je nog meer oude flyers/posters van de club? Zet ze hier ook bij (met een korte beschrijving
in dit bestand) — hoe meer voorbeelden, hoe beter de richtlijnen aangescherpt kunnen worden.
